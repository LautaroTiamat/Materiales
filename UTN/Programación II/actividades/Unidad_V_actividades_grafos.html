Antes de empezar

En estas actividades vas a practicar todo lo que vimos sobre grafos: vértices, aristas, grados, caminos, tipos de grafos y cómo guardarlos en un programa. Van de lo más fácil a lo más difícil, así que conviene hacerlas en orden: cada una usa algo que aprendiste en la anterior.

Cómo está armada cada actividad

  • Repaso: un recordatorio corto del tema, con un ejemplo resuelto sobre un grafo distinto al de la actividad.
  • Parte A · en papel Dibujás el grafo y respondés a mano. No te la saltees: si no sabés resolverlo en papel, tampoco vas a saber programarlo.
  • Parte B · en PHP Programás lo mismo. Para cada método te explicamos qué recibe, qué devuelve y cómo pensarlo paso a paso.
  • Pistas: están escondidas. Abrilas solo si te trabás.
  • Salida esperada: lo que tiene que mostrar tu programa. Usala para comprobar que tu código funciona y que tus respuestas de la Parte A eran correctas.

Cómo guardamos un grafo en PHP: la lista de adyacencia

Como en el apunte, vamos a guardar el grafo en un array asociativo: cada clave es un vértice y su valor es un array con sus vecinos (los vértices con los que está conectado).

$ady = [
    "X" => ["Y", "Z"],
    "Y" => ["X", "Z"],
    "Z" => ["X", "Y", "W"],
    "W" => ["Z"],
];

Fijate que la arista X–Y aparece dos veces: Y está en la lista de X, y X está en la lista de Y. Eso pasa porque el grafo es no dirigido: la conexión vale para los dos lados. En un grafo dirigido (con flechas), cada flecha se anota una sola vez, en la lista del vértice de donde sale.

Vamos a usar este grafo de ejemplo (X, Y, Z, W) en varios repasos.

Cómo ejecutar tu programa en el navegador

  1. Encendé el servidor local. Abrí XAMPP (o el que usemos en clase) y tocá Start en Apache. Tiene que quedar en verde.
  2. Guardá tus archivos dentro de la carpeta del servidor. En XAMPP es htdocs (en Windows suele ser C:\xampp\htdocs). Creá ahí una carpeta para esta unidad, por ejemplo grafos, y guardá cada actividad en su propio archivo: actividad1.php, actividad2.php...
  3. Abrí el navegador y escribí la ruta con localhost. La dirección es localhost + la ruta de tu archivo a partir de htdocs: 
    http://localhost/grafos/actividad1.php
    Si tu carpeta tiene otro nombre, cambiá esa parte. Por ejemplo, para htdocs/prog2/unidad5/actividad3.php la dirección es http://localhost/prog2/unidad5/actividad3.php.
  4. Cada vez que cambies el código, guardá el archivo y recargá la página (F5) para ver el nuevo resultado.
Importante: poné esta línea al principio de cada archivo En las actividades imprimimos con echo "...\n". El navegador, por defecto, lee la salida como una página web: ignora los \n y te muestra todo pegado en una sola línea. Para que respete los saltos de línea (y también las tildes), agregá esta línea justo después de <?php: 
<?php
header("Content-Type: text/plain; charset=utf-8");
Con eso, lo que ves en el navegador queda igual que la «salida esperada» de cada actividad.
Si no funciona
  • «No se puede acceder a este sitio»: Apache no está encendido.
  • «Not Found» / 404: la ruta está mal escrita o el archivo no está dentro de htdocs. Revisá mayúsculas, minúsculas y el nombre de la carpeta.
  • Ves el código en lugar del resultado: abriste el archivo con doble clic (la dirección empieza con file:///). Tiene que empezar con http://localhost/.
  • Página en blanco: probablemente hay un error de sintaxis. Revisá los ;, las llaves y las comillas.

1Rutas del Gran Resistencia

vérticesaristasG = (V, A)no dirigido

Objetivo: representar un grafo real, identificar sus vértices y aristas, y crear la clase Grafo que vas a reutilizar en las demás actividades.

Repaso Un grafo es G = (V, A): un conjunto V de vértices (los objetos) y un conjunto A de aristas (las conexiones). Si las aristas no tienen dirección, se escriben como pares no ordenados con llaves: {X, Y} es lo mismo que {Y, X}.
Ejemplo resuelto (grafo X, Y, Z, W) V = { X, Y, Z, W } → 4 vértices.
A = { {X, Y}, {X, Z}, {Y, Z}, {Z, W} } → 4 aristas.
En la lista de adyacencia hay 2 + 2 + 3 + 1 = 8 anotaciones, porque cada arista se anotó dos veces. Por eso 8 / 2 = 4 aristas.

Los datos

Estas localidades están unidas por rutas de doble mano:

DesdeHasta

ResistenciaFontana
ResistenciaPuerto Tirol
ResistenciaCorrientes
FontanaPuerto Tirol
BarranquerasPuerto Vilelas
Parte A · en papel
  1. Dibujá el grafo. Hacé un círculo por cada localidad (son los vértices) y una línea por cada ruta (son las aristas). No importa dónde ubiques cada círculo: lo que importa es qué está conectado con qué.
  2. Escribí el conjunto V con todas las localidades, sin repetir.
  3. Escribí el conjunto A con todas las rutas, usando llaves: {Resistencia, Barranqueras}, ...
  4. Contá cuántos vértices y cuántas aristas tiene.
  5. Respondé: ¿es un grafo dirigido o no dirigido? Justificá con el enunciado.
  6. Escribí la lista de adyacencia a mano, como en el ejemplo de la introducción. Para cada localidad, anotá con quiénes está conectada.
Parte B · en PHP

Creá la clase Grafo con dos atributos privados:

private array $ady = [];     // la lista de adyacencia
private bool $dirigido;      // true si las aristas son flechas

El constructor recibe bool $dirigido = false y lo guarda. Después programá estos métodos:

agregarVertice(string $v): void

Agrega un vértice nuevo, que empieza sin vecinos.

  1. Preguntá si $v ya existe como clave en $this->ady (usá isset).
  2. Si no existe, creala con un array vacío: $this->ady[$v] = [];

¿Por qué preguntar primero? Si el vértice ya tenía vecinos y le asignás [], los borrás todos.

agregarArista(string $a, string $b): void
  1. Llamá a agregarVertice con $a y con $b, para asegurarte de que existen.
  2. Agregá $b a la lista de $a: $this->ady[$a][] = $b;
  3. Si el grafo no es dirigido, agregá también $a a la lista de $b.
cantidadVertices(): int

Cada vértice es una clave del array, así que alcanza con contar las claves de $this->ady.

cantidadAristas(): int
  1. Recorré la lista de adyacencia con foreach y sumá el count de cada lista de vecinos.
  2. Si el grafo es dirigido, ese total ya es la cantidad de aristas.
  3. Si es no dirigido, cada arista se contó dos veces: devolvé el total dividido por 2 (con intdiv).
mostrar(): void

Recorré con foreach ($this->ady as $v => $vecinos) e imprimí cada vértice con sus vecinos separados por coma (usá implode).

Por último, fuera de la clase, creá el grafo, cargá las 6 rutas y mostrá el resultado:

$rutas = new Grafo();
$rutas->agregarArista("Resistencia", "Barranqueras");
// ... las otras 5 rutas
$rutas->mostrar();
echo "Vértices: " . $rutas->cantidadVertices() . "\n";
echo "Aristas: " . $rutas->cantidadAristas() . "\n";
Errores comunes
  • Olvidarse de anotar la arista en los dos sentidos: Corrientes aparecería sin vecinos.
  • Devolver la suma de los count sin dividir por 2: te daría 12 aristas en lugar de 6.
  • Escribir distinto un mismo nombre ("Pto Tirol" y "Puerto Tirol"): para PHP son dos vértices diferentes.
Pista: cómo imprimir una línea de mostrar()
echo "$v -> [" . implode(", ", $vecinos) . "]\n";

2Grado de cada vértice

gradopar / imparaisladoterminalsuma de grados

Objetivo: calcular el grado de cada vértice, clasificarlo y comprobar la regla de la suma de grados.

Repaso
  • El grado de un vértice es la cantidad de aristas que inciden en él (cuántas conexiones tiene).
  • Es par si el grado es 0, 2, 4...; es impar si es 1, 3, 5...
  • Un vértice aislado tiene grado 0: no está conectado con nadie.
  • Un vértice terminal tiene grado 1: es el final de una rama.
  • Regla: la suma de los grados de todos los vértices es igual al doble de la cantidad de aristas, porque cada arista toca dos vértices y se cuenta una vez en cada extremo.
Ejemplo resuelto (grafo X, Y, Z, W) X: grado 2 (par) · Y: grado 2 (par) · Z: grado 3 (impar) · W: grado 1 (impar, terminal).
Suma: 2 + 2 + 3 + 1 = 8. El grafo tiene 4 aristas, y 8 = 2 × 4. ✓
En la lista de adyacencia, el grado es simplemente el largo de la lista: count($ady["Z"]) da 3.

Los datos

Grafo no dirigido con estas aristas:

A–B, A–C, A–D, B–D, C–D, D–E, D–F

Además existe el vértice G, que no tiene ninguna arista.

Parte A · en papel

  2. Para cada vértice, contá las líneas que salen de él. Truco: tachá cada arista de la lista a medida que la contás para sus dos extremos.
  3. Completá la tabla:
    VérticeGrado¿Par o impar?¿Aislado / terminal / ninguno?
    A
    B
    C
    D
    E
    F
    G
  4. Sumá todos los grados y compará el resultado con la cantidad de aristas. ¿Se cumple la regla?
  5. Pensá: ¿puede existir un grafo cuya suma de grados sea un número impar? ¿Por qué?
Parte B · en PHP

Partí de la clase Grafo de la Actividad 1 (este grafo es no dirigido) y agregale estos métodos:

grado(string $v): int

Devolvé el count de la lista de vecinos de $v. Usá ?? [] para que, si el vértice no existe, devuelva 0 en lugar de dar un error.

clasificar(string $v): string
  1. Calculá el grado llamando a $this->grado($v).
  2. Si el resto de dividir por 2 (% 2) es 0, el texto empieza con "par"; si no, con "impar".
  3. Si el grado es 0, agregale ", aislado". Si es 1, agregale ", terminal".
  4. Devolvé el texto.
sumaDeGrados(): int

Recorré todos los vértices (array_keys($this->ady)) y acumulá el grado de cada uno en una variable que empieza en 0.

vertices(): array

Devolvé array_keys($this->ady). Como $ady es privado, necesitás este método para poder recorrer los vértices desde afuera de la clase.

Para cargar G sin aristas, usá agregarVertice("G"). Después recorré los vértices, mostrá el grado y la clasificación de cada uno, y verificá la regla de la suma.

Errores comunes
  • No cargar G: si nunca llamás a agregarVertice("G"), G no existe en el grafo.
  • Pensar que 0 es impar: 0 es par (0 % 2 da 0).
Pista: cómo armar el texto de clasificar()
$texto = ($g % 2 === 0) ? "par" : "impar";
if ($g === 0) {
    $texto .= ", aislado";     // .= agrega al final del string
}

3Seguidores en Instagram

grafo dirigidopares ordenadosgrado de entradagrado de salida

Objetivo: trabajar con un grafo dirigido y distinguir las flechas que salen de un vértice de las que llegan a él.

Repaso En un grafo dirigido las aristas son flechas: van en un solo sentido. Se escriben como pares ordenados con paréntesis: (P, Q) va de P hacia Q y no es lo mismo que (Q, P).
  • Grado de salida: cuántas flechas salen del vértice.
  • Grado de entrada: cuántas flechas llegan al vértice.
Ejemplo resuelto 
$ady = [
    "P" => ["Q", "R"],
    "Q" => ["P"],
    "R" => [],
];
P: salida 2, entrada 1 · Q: salida 1, entrada 1 · R: salida 0, entrada 1.
P y Q se siguen mutuamente (hay flecha de ida y de vuelta). P y R no: solo hay flecha de P hacia R.
Fijate que la salida es el largo de la lista, pero para la entrada hay que buscar en todas las listas: R aparece en la lista de P, así que tiene entrada 1.

Los datos

La arista (Ana, Beto) significa «Ana sigue a Beto»:

(Ana, Beto), (Beto, Ana), (Ana, Caro), (Caro, Dani), (Dani, Ana), (Eli, Ana)
Parte A · en papel

  2. Completá la tabla:
    PersonaGrado de salida (a cuántos sigue)Grado de entrada (cuántos la siguen)
    Ana
    Beto
    Caro
    Dani
    Eli
  3. ¿Quién es la persona más seguida?
  4. ¿Ana sigue a Caro? ¿Caro sigue a Ana?
  5. ¿Qué pares de personas se siguen mutuamente?
  6. ¿Hay alguien a quien nadie siga?
  7. Comprobá: sumá todos los grados de salida. ¿Cuánto da? ¿Coincide con la cantidad de aristas? ¿Por qué acá no se cumple «el doble»?
Parte B · en PHP

Creá una clase nueva, GrafoDirigido. Es como Grafo, pero siempre es dirigido.

agregarArista(string $a, string $b): void

Igual que en la Actividad 1, pero anotá solamente $b en la lista de $a. No hay que anotar la vuelta.

gradoSalida(string $v): int

Es el largo de la lista de $v, igual que el grado de la Actividad 2.

gradoEntrada(string $v): int
  1. Empezá un contador en 0.
  2. Recorré todas las listas de vecinos de la clase.
  3. Cada vez que $v aparezca en una lista (in_array), sumá 1: eso significa que hay una flecha que llega a $v.
  4. Devolvé el contador.
sigue(string $a, string $b): bool

Devolvé si $b está en la lista de $a.

seSiguenMutuamente(string $a, string $b): bool

Reutilizá sigue: tiene que ser verdad que $a sigue a $b y que $b sigue a $a (operador &&).

Es el patrón clásico de buscar el máximo:

  1. Empezá con $mejor = "" y $max = -1.
  2. Recorré los vértices. Si el grado de entrada del vértice actual es mayor que $max, actualizá $max y $mejor.
  3. Al terminar, devolvé $mejor.

Agregá también vertices(): array como en la Actividad 2 para poder recorrer las personas e imprimir la tabla.

Errores comunes
  • Anotar la arista en los dos sentidos: así el grafo deja de ser dirigido y todos «se siguen mutuamente».
  • Calcular el grado de entrada con count de la propia lista: eso es el grado de salida.

4«Personas que quizás conozcas»

vecinosno dirigidoredes sociales

Objetivo: usar los vecinos de los vértices para responder preguntas reales, como hace una red social para sugerirte amigos.

Repaso En una red de amistades, cada persona es un vértice y cada amistad es una arista no dirigida (si Ana es amiga de Beto, Beto es amigo de Ana). Los amigos de una persona son sus vecinos: la lista que ya guardamos en la lista de adyacencia.
Ejemplo resuelto (grafo X, Y, Z, W)
  • Amigos de X: Y, Z. Amigos de W: Z.
  • ¿X y W son amigos? No: W no está en la lista de X.
  • Amigos en común entre X y W: los que están en las dos listas → Z.
  • Sugerencias para X: miro a los amigos de X (Y y Z) y, a su vez, a los amigos de ellos: Y → X, Z; Z → X, Y, W. Descarto a X (es la misma persona) y a Y y Z (ya son amigos de X). Queda W.

Los datos

Ana–Beto, Ana–Caro, Beto–Caro, Beto–Dani, Caro–Eli,
Dani–Eli, Dani–Fede, Eli–Fede, Dani–Gabi

Hugo está en la red, pero no tiene amigos.

Parte A · en papel
  1. Dibujá la red (incluido Hugo).
  2. ¿Quiénes son los amigos de Dani?
  3. ¿Ana y Eli son amigas? ¿Qué amigos tienen en común?
  4. ¿Qué amigos tienen en común Beto y Eli?
  5. ¿A quiénes le sugeriría la red a Ana? Hacelo como en el ejemplo: anotá los amigos de Ana, después los amigos de cada uno de ellos, y tachá a Ana y a los que ya son sus amigos. No repitas nombres.
  6. ¿Y a Hugo? ¿Por qué?
Parte B · en PHP

Creá la clase RedSocial. Por dentro es un grafo no dirigido, pero con nombres de métodos que hablan de personas y amistades.

agregarPersona(string $p): void

Es igual a agregarVertice.

agregarAmistad(string $a, string $b): void

Es igual a agregarArista no dirigida: se anota en las dos listas.

amigos(string $p): array

Devolvé la lista de vecinos de $p (o [] si no existe).

sonAmigos(string $a, string $b): bool

¿Está $b entre los amigos de $a?

amigosEnComun(string $a, string $b): array

Usá array_intersect con las dos listas de amigos. Envolvelo en array_values para que las posiciones queden 0, 1, 2...

sugerencias(string $p): array

Necesitás dos foreach, uno adentro del otro:

  1. Empezá con un array vacío $sug = [].
  2. Recorré cada $amigo de $p.
  3. Adentro, recorré cada $candidato entre los amigos de $amigo.
  4. Agregá al candidato a $sug solamente si se cumplen las tres condiciones:
    • no es la misma persona ($candidato !== $p);
    • todavía no es amigo de $p;
    • no está ya en $sug (para no repetirlo).
  5. Devolvé $sug.

Para imprimir las listas, un truco: si el array está vacío, mostrá (ninguno).

$lista = fn(array $a) => count($a) ? implode(", ", $a) : "(ninguno)";
echo "Sugerencias para Hugo: " . $lista($red->sugerencias("Hugo")) . "\n";
Errores comunes
  • Olvidar la condición $candidato !== $p: Ana aparecería sugerida a sí misma, porque es amiga de sus amigos.
  • No controlar repetidos: Dani aparecería dos veces si llegara por dos amigos distintos.
Pista: la condición del if de sugerencias()
if ($candidato !== $p
    && !$this->sonAmigos($p, $candidato)
    && !in_array($candidato, $sug, true)) {
    $sug[] = $candidato;
}

5¿Es un camino?

caminolongitudsimplecon ciclocerrado

Objetivo: decidir si una secuencia de vértices es un camino y clasificarlo.

Repaso
  • Un camino es una secuencia de vértices donde cada uno está unido al siguiente por una arista.
  • Longitud: la cantidad de aristas que recorre. Siempre es la cantidad de vértices de la secuencia menos 1.
  • Camino simple: no repite ninguna arista.
  • Camino con ciclo: vuelve a pasar por un vértice por el que ya había pasado.
  • Camino cerrado: termina en el mismo vértice donde empezó.
Ejemplo resuelto (grafo X, Y, Z, W)
  • X → Y → Z → W: X–Y existe, Y–Z existe, Z–W existe → es camino, longitud 3, simple, sin ciclo.
  • X → W: no existe la arista X–W → no es camino. No importa que se pueda llegar dando una vuelta: cada paso tiene que ser una arista.
  • X → Y → Z → X: es camino, longitud 3, simple, con ciclo (repite X) y cerrado.
  • Z → W → Z: es camino, longitud 2, pero repite la arista Z–W (la usa de ida y de vuelta), así que no es simple. Además es cerrado.

Los datos

Grafo no dirigido (es el del apunte):

A–E, A–D, A–B, B–E, D–B, B–F, E–F, D–C, C–B
Parte A · en papel
  1. Dibujá el grafo.
  2. Para cada secuencia, revisá de a un paso: ¿existe la arista entre el primer vértice y el segundo? ¿Y entre el segundo y el tercero? Si alguna falta, no es un camino.
  3. Completá la tabla (si no es camino, dejá vacías las otras columnas):
    Secuencia¿Camino?Longitud¿Simple?¿Con ciclo?¿Cerrado?
    D → C → B → F
    A → C
    A → B → E → A
    D → B → F → E → B
    A → B → A
  4. Inventá un camino de longitud 4 que sea simple y cerrado en este grafo.
Parte B · en PHP

Partí de la clase Grafo no dirigida. Cada secuencia se guarda como un array: ["D", "C", "B", "F"].

hayArista(string $a, string $b): bool

¿Está $b en la lista de $a?

esCamino(array $secuencia): bool
  1. Recorré la secuencia con un for desde $i = 0 hasta count($secuencia) - 2 (o sea, la condición es $i < count($secuencia) - 1). Así comparás cada vértice con el siguiente sin salirte del array.
  2. Si no hay arista entre $secuencia[$i] y $secuencia[$i + 1], devolvé false en ese mismo momento.

6De lista a matriz de adyacencia

matriz de adyacencialista de adyacenciasimetría

Objetivo: pasar un grafo de una representación a la otra y entender por qué la matriz de un grafo no dirigido es simétrica.

Repaso La matriz de adyacencia es una tabla de n × n: en la fila del vértice origen y la columna del vértice destino va un 1 si hay arista, y un 0 si no.
  • La diagonal (fila X, columna X) representa los lazos. En estos grafos no hay, así que es todo 0.
  • En un grafo no dirigido, si hay arista de X a Y también la hay de Y a X, así que la matriz es simétrica: la casilla [X][Y] es igual a la casilla [Y][X].
  • En un grafo dirigido eso no tiene por qué pasar.
Ejemplo resuelto (grafo X, Y, Z, W)
XYZW
X0110
Y1010
Z1101
W0010
Cómo se arma la fila Z: los vecinos de Z son X, Y, W → pongo 1 en esas columnas y 0 en el resto.
Comprobá la simetría: [X][Y] = 1 y [Y][X] = 1; [Z][W] = 1 y [W][Z] = 1.
Dato útil: la cantidad de 1 de cada fila es el grado del vértice.

7Torneo «todos contra todos»

grafo completon·(n−1)/2

Objetivo: reconocer un grafo completo, entender de dónde sale su fórmula y generar todas sus aristas con un programa.

Repaso Un grafo es completo si cada par de vértices está unido por una arista. Con n vértices tiene n·(n−1)/2 aristas.
¿De dónde sale? Cada uno de los n vértices se une con los otros n − 1: eso da n·(n−1). Pero así cada arista se contó dos veces (una desde cada extremo), por eso se divide por 2.
Ejemplo resuelto Con 3 equipos (Rojo, Verde, Azul): cada uno juega 2 partidos → 3 × 2 = 6, pero Rojo vs Verde es el mismo partido que Verde vs Rojo → 6 / 2 = 3 partidos: Rojo–Verde, Rojo–Azul, Verde–Azul.
Fijate en cómo los armamos: Rojo contra todos los que vienen después (Verde, Azul); Verde contra los que vienen después (Azul); Azul ya jugó con todos. Así no se repite ningún partido.

★Desafío (opcional): el camino más corto

caminosbúsqueda en anchuracola (FIFO)

Objetivo: encontrar el camino con menos aristas entre dos vértices, como hace un GPS. Es más difícil que las anteriores: hacelo solo si terminaste las otras.

La idea: buscar por capas Desde el vértice de origen, primero miramos sus vecinos (están a distancia 1). Después, los vecinos de esos (distancia 2). Y así, capa por capa. La primera vez que aparece el destino, encontramos el camino más corto.
Para recorrer en ese orden usamos una cola (la estructura FIFO que ya vieron): el primero que entra es el primero que sale. Además, para cada vértice anotamos desde dónde llegamos, para poder reconstruir el camino al final.
Ejemplo resuelto: de X a W (grafo X, Y, Z, W)
PasoSaco de la colaVecinos nuevosAnoto en $anteriorCola después
Inicio——X ← nadie[X]
1XY, ZY ← X, Z ← X[Y, Z]
2Y(X y Z ya los vi)—[Z]
3ZW → ¡es el destino!W ← Zterminé
Reconstrucción, de atrás para adelante: W vino de Z, Z vino de X, X no vino de nadie. Dado vuelta: X → Z → W (longitud 2).

Los datos

Usá el grafo de la Actividad 5 y agregale una «isla» separada: la arista G–H.

Parte B · en PHP
caminoMasCorto(string $desde, string $hasta): ?array

El ?array significa que devuelve un array o null (cuando no hay camino).

  1. Si $desde y $hasta son iguales, devolvé [$desde].
  2. Creá $anterior = [$desde => null] (el origen no vino de nadie) y $cola = [$desde].
  3. Mientras la cola no esté vacía:
    • Sacá el primero: $actual = array_shift($cola);
    • Recorré los vecinos de $actual. Para cada vecino que todavía no esté en $anterior (usá array_key_exists):
      • anotá $anterior[$vecino] = $actual;
      • si el vecino es $hasta, reconstruí el camino y devolvelo;
      • si no, agregalo al final de la cola: $cola[] = $vecino;
  4. Si la cola se vació sin encontrar el destino, devolvé null.
private reconstruir(array $anterior, string $hasta): array

Empezá en $hasta y andá «para atrás» con $anterior hasta llegar a null. Cada vértice que visites, agregalo al principio del camino con array_unshift, así queda en el orden correcto.

¿Por qué array_key_exists y no isset? Porque $anterior[$desde] vale null, e isset devuelve false para las claves que valen null. Con isset, el programa creería que nunca visitó el origen.
Pista: el for de reconstruir()
$camino = [];
for ($v = $hasta; $v !== null; $v = $anterior[$v]) {
    array_unshift($camino, $v);
}
return $camino;
